# Alloplex Biotherapeutics

> Alloplex Biotherapeutics, Inc. is a privately held clinical-stage cellular immunotherapy company
> founded in 2016 and headquartered in Woburn, Massachusetts, with a wholly owned subsidiary,
> Alloplex Australia Pty Ltd, in Adelaide, South Australia. It develops non-engineered, autologous
> multi-cellular therapies intended to retrain a patient's own immune system against solid tumors
> and autoimmunity. Its ENLIST platform uses an irradiated, engineered melanoma cell line expressing
> multiple immunomodulatory factors to activate, differentiate and expand a patient's peripheral
> blood mononuclear cells; the resulting product, SUPLEXA, is manufactured by a defined,
> GMP-compatible process using no genetic engineering and no feeder cells. The first-in-human Phase 1
> SUPLEXA-101 trial in Australia (35 patients with metastatic solid tumors) met its endpoints, and
> the FDA granted SUPLEXA Fast Track designation for MSI-H colorectal cancer.

## What API surface exists

Alloplex Biotherapeutics runs **no developer program**. There is no product API, no developer
portal, no API documentation, no SDK, no CLI, no sandbox, no OpenAPI, no status page and no support
channel for developers. `/developers/`, `/api/`, `/docs/` and every `/.well-known/` path return 404,
verified against a negative control.

The **only** machine-readable surface reachable without credentials is the WordPress REST content
API behind the corporate site — the CMS's own content surface, not a product:

- Base URL: https://alloplexbio.com/wp-json
- Anonymous, read-only. The REST index returns `"authentication": []`.
- 219 routes across 12 namespaces; 19 operations return data without credentials.
- Contents at harvest: 61 posts, 19 pages, 225 media items, 11 category terms, 0 tags.
- Upstream contract: https://developer.wordpress.org/rest-api/

Two agent-shaped surfaces are **registered but gated**: a WordPress MCP adapter endpoint
(`POST /wp-json/mcp/mcp-adapter-default-server`) and the WordPress Abilities API
(`wp-abilities/v1`). Both return `401 rest_forbidden` anonymously, so no MCP server and no agent
capability registry is claimed for this provider. No A2A agent card is published.

## Using the content API

- `GET /wp/v2/posts` — 61 press releases, clinical/scientific news, conference notes, opinion pieces. `content.rendered` is fully populated.
- `GET /wp/v2/pages` — 19 corporate pages. All top-level. The FAQ page (1019) returns an empty body.
- `GET /wp/v2/media` — 225 attachments including PDF documents.
- `GET /wp/v2/categories` — 11 terms carrying all editorial grouping.
- `GET /wp/v2/search?search=SUPLEXA` — cross-content search.
- Pagination totals are in the `X-WP-Total` / `X-WP-TotalPages` headers, never in the body.
- `_fields` is the most useful parameter for controlling payload size.

### Known gaps an agent should not trip on

- The `tags` taxonomy is registered but empty — group by `categories`.
- `author` is a populated integer but unresolvable: `/wp/v2/users` returns 401.
- The site's sitemaps advertise `publication`, `team_member`, `conference` and `resource` types that
  are **not** REST-registered — requesting them returns `404 rest_no_route`. Scientific publications,
  leadership bios and conference appearances are HTML-only.
- No rate-limit headers. `robots.txt` requests `Crawl-delay: 10`.
